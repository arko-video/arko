# Revues du jour (Romain → Claude)

Chaque jour, avant d'envoyer sur YouTube ou TikTok, Romain écrit ici ce qu'il a changé à la main dans le montage
d'Arko et ce qu'il trouve à améliorer. Claude lit ces fichiers au début de la session suivante, transforme chaque
remarque en un cas du banc réel (`tests/banc-reel/`) ou en un réglage du monteur sans IA, puis note ce qui a été fait.

Un fichier par jour : `AAAA-MM-JJ.md`, avec ce modèle :

```
## Vidéo : <titre>  (TikTok / YouTube)
### Ce que j'ai changé à la main
- 03:12 coupe trop tôt, j'ai rallongé de 1 s
- perso de Guts affiché alors que c'était moi qui parlais (vers 05:40)
### Ce qui manque / à améliorer
- ...
### Fait par Claude (rempli par Claude)
- ...
```
